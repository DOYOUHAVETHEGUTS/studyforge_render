Scheduled delivery

Sends the next queued section from your active material automatically — the same as clicking "Send next to inbox" yourself. This runs as a background loop inside StudyForge, so it only fires while python -m studyforge.cli serve is running. For delivery that must happen even when you're not keeping the app open, use your OS's task scheduler to run python -m studyforge.cli send instead — see the README.

Custom agent prompts (advanced)

Two ways to override an agent's built-in prompt: (1) paste your Claude Managed Agents agent_... ID below and click Sync — StudyForge fetches that agent's system prompt via the Managed Agents API and fills the box for you, or (2) paste prompt text directly. StudyForge always runs the fast, stateless Messages API per section — it does not run your agents as Managed Agent sessions (that runtime is built for tool-using/sandboxed work and bills separately per session-hour, which buys nothing here). Leave everything blank to use StudyForge's built-in default.
